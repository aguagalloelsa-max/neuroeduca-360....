NEUROEDUCA 360° — Ecosistema Educativo Digital
================================================

Archivo principal:
- index.html

Uso:
1. Abra index.html en un navegador moderno.
2. Para publicarlo, suba el archivo como sitio estático a un servicio de alojamiento web.
3. Los cuatro productos previos están enlazados desde la biblioteca del ecosistema.
4. El progreso de gamificación se guarda con localStorage del navegador.

Nota:
- La sección de IA incluye un simulador local de tutor socrático y un prompt maestro para una herramienta de IA generativa.
- No se incluyen claves API ni se envían automáticamente datos personales a servicios externos.
